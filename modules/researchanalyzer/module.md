# ResearchAnalyzer

标识rh_analyzer。核验研究适用性、组织事实底稿、登记确定性计算并检验解释与反证。输入为同版已留存依据、用户假设及必要问题；输出为计算、问题回答、适用限制和缺口。

实现位于modules/researchanalyzer/src，负责研究适用性和数字一致性。共享方法登记在core/src/researchhelper/contracts.py。执行方法从Session.tools.calculations读取，不能运行模型生成的金融代码。

区分数值正确、来源有效和金融适用性。价格变化不自动等于总回报，经营改善不自动等于投资机会。未知条件不能补默认值。

首次草稿的原值算术在draft_analysis.py独立登记，不进入已核验计算方法名单。先按任务、字段、期间、字面单位及报表口径分组，再计算区间变化、同比、原值利润率和现金流原值比；未知金额单位仅在等尺度条件下展示。亏损、非正基数、冲突或缺失只影响对应结果，不阻断出稿。App与Skill读取同一结果，不让模型重算数字或把收盘价范围称为振幅。

interpretation_context根据本次实际观测给出对象对应的写作边界，App与Skill共用。计算condition随结果送入首稿；合并现金流与归母净利润、余额与流量、年度利润与TTM分母、宏观读数与贡献分别区分。这是同次写作的依据，不新增模型、复核步骤或强制取数，不批准金融结论。新报告冻结所提供的上下文，旧报告不回填。

按待验证解释组织数据与计算，比较相反解释，说明证据到判断的连接；数据复述和比率正确不等于完成机制或投资问题。共享research_outline同时供App、Skill与原有独立复核使用，不增加第二套研究或单独的报告总结调用。

宏观序列单位明确为%时，登记方法可计算实际起终读数与最近两期读数的百分点差。两者都保留实际日期，不称为CPI环比、相对涨幅或市场因果；未知单位不猜，原始序列仍可出稿。

ETF单位净值支持同一序列实际起终读数的变化率和范围，覆盖iFinD单位净值字段与交易所PCF原值。结果保留所属日期、精度与原始引用，未知单位仍附同尺度条件；缺少中间值不抹去有效端点，缺失或非正端点不自动替换。读数变化不作分红再投资、份额折算和个人现金流调整，不能称为持有人总回报。相关写作提示按实际出现净值的对象提供，不触发额外取数或模型调用。

口径依据：[深圳证监局基金分红说明](https://www.csrc.gov.cn/shenzhen/c105614/c7521979/content.shtml)，分红会使单位净值下降，现金分红与红利再投资的处理不同。此说明只支持通用口径，不是具体基金的分红事实或本次取数权限。

结构化数字的展示单位由内核附加。相邻普通文字重复同一完整单位时只显示一次；数值、正负号、引用和其他正文仍须逐项匹配。保留原始数字片段，重新生成正确的展示位置和哈希；原文直引及元旦等正常词语不改写。兼容只有重复单位差异的旧格式，不接受借此更改数字或来源。

已知错误使用共享档案的同版更正记录，不能把增加注释当成原稿已修复。正文修订另存版本，保留原值、计算、数据取得日期及旧稿；当前模板与复核引导不自动批准旧报告中的推断。

Tinyshare原字段通过登记的指标对照参与同源原值计算，字段名称、来源与行定位仍保留。收入和报表净利润按实际end_date比较；公告日期不代替报告期。不同供应商、接口或报表范围不因字段同名而拼接；未知金额单位附等尺度条件，不自动形成已核验财务比率。

财务图表使用同一指标对照重新验证计算输入。Tinyshare财务原字段不会被冒充为iFinD字段；单位未明的金额在对客图表中不显示成普通金额曲线，优先使用已复算的可比变化率，并保留尺度条件。原始金额、字段和行引用继续进入底稿及结构化导出。

新稿根据实际取得的收入、利润和成本字段提供利润归因说明。收入、毛利与净利润的增长率不能直接比较变动贡献，收入成本差占比不代表单位产品毛利。未知项可作竞争解释，不新增分解义务或交付阻断。估值读数仍可连接盈利兑现与风险补偿的条件性逻辑，单位沿用原值口径。
