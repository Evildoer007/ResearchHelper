# ResearchDesigner

标识为`rh_visual`。读取同任务同版本的研究结果、观测和计算，生成离线HTML、图表、公式与打印版面。标准报告和内部详版共用冻结内容，由ReportComposer组织。ArtifactExporter从保存的HTML转换其他格式。

## 何时读取

- 研究和撰稿默认沿用自动选图。查阅[可视化指南](../../docs/VISUAL_LIBRARY.md)时，先找这条逻辑需要回答的比较、趋势、结构或关系。
- 复核单图时读取其原值、单位、期间、引用和支持的图型。App可从报告进入图表方案，Skill用`session.visuals`查询登记，导出时用`visual_profile`应用相容的方案。
- 修改表现样式时检查标准版、详版和打印。锁定证据、数值、主题及报告模板的来源。

## 从论点到图表

1. `draft_visuals.py`从本条论点提取证据引用。`evidence_visuals.py`用同任务同版本的证据选择补充视角。`visual_selection.py`检查数据形状并提供原值表。图库原型只展示能力，实际报告沿用本任务取证结果。
2. 一两个读数用简洁文字和来源定位。时间序列至少有三个实测值和一段连续观测，缺期画断点。同一对象同窗口的价格与估值可并列，各用自身的标尺。两期分组、阶段变化及财务比率共用明确的单位与分母。
3. 后续论点重复引用同区间观测时可链接前图。只有端点属于论据时，已留存的原件中间点可作为绘图上下文。中间点只取自同版同原件，保留实际日期及缺失状态。上下文与论据引用分别记录，底稿可逐项定位。
4. 统计、估值、收益、回撤和归因图需要可核对的计算或已披露结果。事实、假设和条件可用清楚的路径图组织，箭头不代表概率、数值权重或已经验证的因果。公告时间轴按实际披露时点区分已发生和待观察。
5. 缺少必要口径、来源冲突、只剩孤立点或数值超出安全绘图精度时，回退成有依据的文字或表格。应用继续交付其他可用内容。逐条配图及来源保存在呈现文档的`figure_coverage`与`visual_sources`中。

## 图表、阅读和转换

- `visual_catalog.py`登记方案、适用性和配色，并生成`visual-catalog-data.js`。`visual-library.js`用离线ECharts渲染。图库按趋势与行情、比较与估值、结构与分解、关系与事件、分布与情景组织。双变量图保留横纵轴，数值图保留对应标尺。默认关闭装饰网格、悬浮十字线和折线逐点标记。零线用实线，具有明确含义的比较基准可使用虚线。
- 日期显示使用已绑定原值的有效日历日期。季度、半年和报告期间沿用原名。异常或未经确认的单位保留实际口径。基期、采样窗口、量纲和标尺与图同行，来源可通过图题或原值访问。缩小阅读宽度时为刻度和图注留空间。
- `report_designer.py`将内容填入已有的`report-standard`或`report-detailed`模板。图表采用能容纳标尺和标签的分组，详版逐项增加对应论点的依据与方法。短图文组在A4上尽量整块排版，长正文自然跨页。能完整放入一页的表格整块排版，长表可跨页并保留全部行与表头。公式、适用条件、原值和计算结果按同一计算分组。
- HTML内联冻结素材。系统打印和原生PDF采用A4与7mm边距，打印后恢复阅读版。Word和静态图形使用同一组数据、计算和来源。换图或配色保留内容与版本引用，既有报告继续用各自的冻结呈现。打印采用浅底。视觉规则变更不触发新取证或新模型推理。

## 专题图形与验收

券商历史案例的证据组合由`evidence-charts.js`提供，覆盖散点与原值账表、盈利变化与基准、估值分位与ROE、基准指数瀑布、分红点阵及区间比较。图形使用样稿数据，派生量保留计算口径与依赖。组合图可定位到同版原值。通用配图使用同一个登记目录。

改动后按实际阅读尺寸检查桌面、窄窗、移动端和A4打印。核对每幅图的论点、引用、坐标、单位、标注、静态导出和内容哈希。优先复用真实留存样本。开发仓库的`tests/test_automatic_report_visuals.py`和`tests/test_visual_library.py`覆盖选型、原值和样式切换。
