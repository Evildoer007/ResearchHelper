# EvidenceCollector

标识rh_evidence。负责主体解析、数据获取、原件解析、来源与提取校验。输入为同任务问题、截止时点、取数或阅读范围；输出为原件、响应、定位及来源核验记录，不直接批准投资结论。

实现位于modules/evidencecollector/src，负责取数、原件、解析、来源定位与时点核验。宿主从core/session.py的tools、snapshot、material、read接口取得本任务契约，按references/evidence.md提交依据。

iFinD优先。权限未知、空数据或解析失败明确记录，不静默换源、不编造摘录。不能读取其他产品凭据或扩大对象范围。

financial_data.py是已取得半年报的确定性读取模块，不发起下载或模型调用。按明确标的和两期六个月期间，分别交出四类核心金额、资本开支、现金流调节、非经常性损益、管理层讨论及原件口径，保留单元格、单位、期间、原文定位和缺项。当前单模块实测为比亚迪两期半年报，不代表所有报表版式均受支持，也不改变iFinD结构化数据优先的请求顺序。

读取完整、金额加总通过、来源可采用、研究结论成立分别记录。缺失期间只影响对应字段；接口返回单位缺失时不按金额大小推定单位。该数据产品不写入已采用证据、不回答研究问题，不以原件内容可读替代金融适用性及语义分析。原件只在接口不覆盖所需字段或口径、且已有明确需求时取得，已下载原件复用，不重复请求。

登记的data_pool可取得指数成分原始名单，目前仅有上证50配置。日期、字段、代码和同任务查询留痕通过后，返回代码仅供后续明确选样取数；名单、数量吻合及接口成功均不批准完整性、权重、历史可得性或金融数值。未登记指数保留缺口，不猜板块ID。

实际名单之后的行情可按references/runtime.md显式选择candidate_code_reference核对原值，仍不确认名称、历史身份或名单资格；该引用不批准名单本身，也不替代独立适用性核验。
# 首次报告的数据读取

draft_sources统一读取已取得的行情、财务、宏观月度字符串数值、ETF净值、指数权重及材料正文。区分观测日和披露日，保留原始缺值、证券代码、名称与来源口径，不把读取成功升级为金融核验通过。交给模型的是正文与结构化数据，不包含原件Base64编码。新建研究及主动更新的新版本采用现行规则，历史行情及日期序列按请求代码、日期、字段及研究截止日逐行读取；歧义日期和错位列仅影响对应观测。新任务采用第二版范围读取，保留接口支持的三种日日期字面格式；已交付任务保持原读取版本。原响应完整保留，可用部分仍出稿，未请求的数字不混入规划或正文输入。港股只采用本任务实际get_thscode返回的供应商代码，不自行补零。


主动更新采用现行读取规则并重新绑定输入；打开或恢复旧版不升级读取规则，已交付的原件、报告和内容哈希保留。

初稿读取财务字段时，报告期取同字段请求的D参数。响应time、观测日和取得时间不替代报告期。D未明确时保留数值及原件，标为期间未明确，不影响其他有效资料出稿；不能把两个未知期间当作同期间。规则在新任务和主动更新的新版本中采用，旧版规则保留。

单位元数据与数值原件分别留存定位。版本8按同任务、同版本和原始哈希引用指标目录；同一指标目录的单位不一致时不静默取最后一条，缺项仅限制相关单位判断。数值、其他已明确单位及出稿继续。限定财务校准和行情字段定义按实际范围引用，不称为数值接口字面返回。

相同取数请求复用原响应时，request_purposes逐项保留请求标识、问题关联和实际selection_reason，不用最后一次用途覆盖先前用途。旧版已合并的别名仅保留原来的来源级说明，不猜测历史逐项对应关系。用途不属于事实或核验结论。
