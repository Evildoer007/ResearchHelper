# EvidenceCollector

标识rh_evidence。负责主体解析、数据获取、原件解析、来源与提取校验。输入为同任务问题、截止时点、取数或阅读范围；输出为原件、响应、定位及来源核验记录，不直接批准投资结论。

实现位于modules/evidencecollector/src，负责取数、原件、解析、来源定位与时点核验。宿主从core/session.py的tools、snapshot、material、read接口取得本任务契约，按references/evidence.md提交依据。

iFinD优先。权限未知、空数据或解析失败明确记录，不静默换源、不编造摘录。不能读取其他产品凭据或扩大对象范围。

官方目录的原始HTML完整留存。已经解析成目录记录的文件不再列入待恢复材料，另行上传的文件仍按各自状态处理。目录不能替代公告正文或投资依据。

必要原件先保存字节和下载记录，再解析。解析中断时，优先用Session.retry_original恢复同一留存原件，不重复下载。恢复保留原来源、取得时间、研究问题和累计用量；新摘录仍分别核对来源与金融适用性。对客报告已交付后，重复读取相同来源不增加待补输入，不改写旧报告。原件仍无法读取时保留缺项，继续使用其他已取得依据，不反复重解析或改用未授权来源。

financial_data.py是已取得半年报的确定性读取模块，不发起下载或模型调用。按明确标的和两期六个月期间，分别交出四类核心金额、资本开支、现金流调节、非经常性损益、管理层讨论及原件口径，保留单元格、单位、期间、原文定位和缺项。当前单模块实测为比亚迪两期半年报，不代表所有报表版式均受支持，也不改变iFinD结构化数据优先的请求顺序。

读取完整、金额加总通过、来源可采用、研究结论成立分别记录。缺失期间只影响对应字段；接口返回单位缺失时不按金额大小推定单位。该数据产品不写入已采用证据、不回答研究问题，不以原件内容可读替代金融适用性及语义分析。原件只在接口不覆盖所需字段或口径、且已有明确需求时取得，已下载原件复用，不重复请求。

登记的data_pool可取得指数成分原始名单，目前仅有上证50配置。日期、字段、代码和同任务查询留痕通过后，返回代码仅供后续明确选样取数；名单、数量吻合及接口成功均不批准完整性、权重、历史可得性或金融数值。未登记指数保留缺口，不猜板块ID。

实际名单之后的行情可按references/runtime.md显式选择candidate_code_reference核对原值，仍不确认名称、历史身份或名单资格；该引用不批准名单本身，也不替代独立适用性核验。
# 首次报告的数据读取

draft_sources统一读取已取得的行情、财务、宏观月度字符串数值、ETF净值、指数权重及材料正文。区分观测日和披露日，保留原始缺值、证券代码、名称与来源口径，不把读取成功升级为金融核验通过。交给模型的是正文与结构化数据，不包含原件Base64编码。新建研究及主动更新的新版本采用现行规则，历史行情及日期序列按请求代码、日期、字段及研究截止日逐行读取；歧义日期和错位列仅影响对应观测。新任务采用第二版范围读取，保留接口支持的三种日日期字面格式；已交付任务保持原读取版本。原响应完整保留，可用部分仍出稿，未请求的数字不混入规划或正文输入。港股只采用本任务实际get_thscode返回的供应商代码，不自行补零。


主动更新采用现行读取规则并重新绑定输入；打开或恢复旧版不升级读取规则，已交付的原件、报告和内容哈希保留。

初稿读取财务字段时，报告期取同字段请求的D参数。响应time、观测日和取得时间不替代报告期。D未明确时保留数值及原件，标为期间未明确，不影响其他有效资料出稿；不能把两个未知期间当作同期间。规则在新任务和主动更新的新版本中采用，旧版规则保留。

单位元数据与数值原件分别留存定位。版本8按同任务、同版本和原始哈希引用指标目录；同一指标目录的单位不一致时不静默取最后一条，缺项仅限制相关单位判断。数值、其他已明确单位及出稿继续。限定财务校准和行情字段定义按实际范围引用，不称为数值接口字面返回。

相同取数请求复用原响应时，request_purposes逐项保留请求标识、问题关联和实际selection_reason，不用最后一次用途覆盖先前用途。旧版已合并的别名仅保留原来的来源级说明，不猜测历史逐项对应关系。用途不属于事实或核验结论。

初稿取数覆盖按本次请求的对象、字段及财务报告期检查，单个数字不能代替整个请求完成。后续相同报表口径的资料可补齐原缺项；金额单位未明确不因此重取数或阻断出稿。覆盖结果供App和Skill共同决定补取或调整论点，不表示金融口径已核验。

# 数据来源模块

source_catalogue.py统一描述行情估值、财务经营、公司公告、宏观政策和指数ETF五类能力，App与Skill共用。official_sources.py负责固定政策栏目和留存目录选择，announcement_sources.py负责巨潮与披露易的实际证券映射、日期检索、分页及原件地址，source_transport.py仅负责有边界的网络传输。具体使用范围见[数据获取](../../references/evidence.md)。

每次HTTP发送单独计入原任务预算；同参数响应及同一原件复用。公告JSON响应在解析前通过引擎日志持久化，不伪装为用户材料；取消或重启后复用完整响应，缺少发行人映射时不重复发送已完成的公告查询。HTML或PDF原件保留原始字节与页段。标题不作正文，列表时间不代替首发核验。未取到的资料留缺项，其余有效资料继续出稿。

Tinyshare原始记录由tinyshare_sources.py按已登记接口读取，App与Skill共用。日线、ETF行情、每日指标、利润表和现金流量表保留原字段与行定位；日期、公告窗口、报告期分别核对。价格单位和成交量采用已登记兼容接口口径，成交额保留千元、股本保留万股、市值保留万元，不在读取阶段换算。财报金额缺少单位依据时保留原值，不推定人民币。新读取策略仅用于新任务和显式更新，旧报告和旧任务的恢复不改写。

新任务和显式更新可为iFinD行情与日期序列选择observation_window，按任务截止日和显式回看天数编译实际请求日期。历史区间直接填写起止日。观测策略3继续按标的、字段选取最后一个有值的日期。全空字段保留缺失，重复的最新单元只排除该字段并记录问题。同一响应同时用于完整序列时保留完整读取。

最近收盘可从同一未填充响应留取日期相邻或由交易日历确认相邻的前收，供登记的日涨跌幅计算引用。前收带原始行定位，在底稿可查。单点的写作读数和趋势图范围沿用原选择。前收缺失、非正或冲突时保留收盘读数和其他可用结论。新任务及主动更新采用策略3，旧任务恢复按原策略读取。

历史模式实际取得的iFinD独立交易日历保留同任务、同版本的查询与响应回执。日期和市场核对后，可用于留存收盘价的历史复算。对客报告注明复盘，底稿保留来源和适用限制。历史可得性与正式金融证据继续独立核验。无绑定的旧响应和导入快照只留原件。

取数提案的id是局部编号。同名但参数或用途不同的后续请求，由共享内核分配独立执行编号；draft_request_serialization保留原提案及映射，相同提案恢复时沿用已记录编号。原件、目录和问题引用不改名。覆盖统计使用实际执行请求，不以后一次同名提案覆盖先前缺项。编号调整本身不产生调用，缓存、预算和失败去重规则继续有效。


财务单位按读取版本复用已核对定义。读取版本9新增贵州茅台2024、2025年度C=1指定八个字段的人民币元口径，依据发行人正式年报与留存API原值逐项校准，不把数值或账号权限写入知识目录。其他标的、期间、报表类型和PE不套用；旧任务保留原版本。字段与期间匹配后不再为同一单位重复下载PDF，缺项继续保留原值和适用限制，不阻断报告。

基础财务读取版本10按实际请求代码选择单元。单一请求可以缺少回显代码；多个请求代码须有逐行或逐表身份依据。代码矛盾、错配和列错位只影响相应数据，原始响应保持不变；规划、写作及计算都使用同一选择结果，有效业务文本继续保留。新版本不会把部分响应记为整份已核验，也不会绕过报告期和报表类型回显核对。App和Skill共用这一规则，旧任务恢复保留原版本，主动更新才采用新版；缺项不阻止初稿保存。

宏观原值读取版本11按实际请求的指标和日期窗口选择单元，统计所属期不代替首发时点。明确晚于截止日的修订数据不参与本版，同一统计期重复时不任取或平均；目录频率矛盾时不猜统计频率。缺少修订信息不阻断当前原值使用，也不批准历史版本或事件因果。原始响应留在底稿，规划、计算、写作和图表采用相同范围，缺项继续保存受限报告。旧任务恢复保留原读取规则，主动更新才采用新版。

主动更新按实际版本核对账号策略与代码映射，旧映射不能抑制本版查询；同版本有效的无匹配结果可复用，不猜代码或反复请求。读取规则12保留前版原件及来源版本，同一查询的新响应取得后以其作为本版读数，不将新旧响应重复计入。缺值保留缺值，同版冲突不按抓取时间擅自裁决；失败或其他查询不替代旧响应。

读取规则14将候选发现和数值取数分别核对。合法的行业、产业链名单按实际返回完成查询，不因缺少行情数字反复检索；研究问题继续按原范围选择身份及业务数据，纯目录问题可直接回答。候选不自动成为行业归属、投资论据或计算样本，缺项不新增出稿阻断；旧规则及既有检查点不迁移。
