# ResearchHelper数据获取

当前优先iFinD固定API，按研究问题选择行情、财务、宏观和电子资料。资料缺项只影响对应结论，不阻断整份初稿，不为出稿默认下载PDF。本轮未使用Wind、Tinyshare或其他产品的凭据。

## 一、取数流程

研究问题先明确对象、期间和数据需要，再读取账号接口策略。代码不明确时使用实际映射结果；字段优先复用已登记的定义与参数。结构化API能回答的问题直接取数，公告或原件只在确需文本时按需取得。

取得的数据保留原响应、请求参数和哈希，逐项区分原值、单位、观测日期和报告期间。金额单位未明确时不按数量级推定；单点、缺值和非正基数不补造。

新任务的历史行情及日期序列按请求代码、字段、日期和研究截止日读取。日期序列采用实际indipara字段，不把响应中的额外数字交给规划或撰稿。错码、越界日期、重复歧义观测或错位列仅影响相应数据；有效部分继续生成报告。筛除的数字不进入规划和撰稿上下文，完整响应仍保留在底稿。旧任务沿用冻结的读取规则。

## 三、从数据到报告

App与Skill共用取证、原值读取、登记计算和报告生成。每条研究逻辑关联实际数据、计算和来源，按数据形状自动选图；条件不够时显示原值表，不补造曲线。先保存HTML，再由同版内容导出其他格式。取数异常、单位条件和核验记录留在ResDesk。

本轮将异常来源及部分异常行情放入实际DMG和独立只读Skill，确认有效观测仍可出稿，两版报告数据一致，原始异常值可追溯但不进入对客数据集。详见[当前交付验收](CURRENT_VERSION.md)。

## 四、既往自主研究与边界

此前已安装App执行过贵州茅台、比亚迪和CPI的一句话研究。茅台留存任务使用2次deepseek-flash调用与6次iFinD请求；本轮不重跑、不增加模型用量。比亚迪的[真实研究及内容复核](../result/acceptance/one-sentence-research-vgjkyxq9/content-review.json)、CPI的[真实研究及内容复核](../result/acceptance/one-sentence-research-lfu94vrd/content-review.json)继续保留。

结构化取数成功不等于归因已成立。经营现金流变化不能直接归因为回款；时点营运资金余额不能直接解释现金流贡献；净值读数不等于分红再投资总回报；宏观共同变化不能替代权重分解或因果识别。当前修订数据不证明历史当时已知信息。

行业、产业链、事件和混合问题的完整模型研究质量仍需逐类检查，不把接口连通或离线回放写成全部PRD通过。

## 五、2026年11月1日定向诊断与字段关联

一次明确要求原始金额与计量单位的iFinD语义查询，返回贵州茅台2025年营业收入、归母净利润与经营现金流原值，均与留存固定API数值一致，但没有返回金额单位或币种，且附带成交量。实际使用1次账号策略请求和1次查询，模型调用0次、PDF下载0份，不重试。该问法尚未登记为App请求语法，只是供应商端点的定向诊断，不把响应成功写成新增财务能力或单位核验通过。[实际响应](../result/acceptance/ifind-unit-query-20261101/receipt.json)。

由此修复共享写作输入：根据原始请求区分主动字段、附带字段、缺列与空值；EDB按指标ID对应。无法从已登记语法确定字段时保留为请求范围未明确，不按关键词猜测。提示不证明主体、时点、单位和整项研究需求已经满足，不阻断已有资料出稿，也不自动重新请求。

实际DMG和独立只读Skill已通过缺列、空值、附带字段的受控验收，原值与两版报告一致；旧报告不重写，原值读取仍为版本8。该验收证明字段交接和报告保存行为，不证明模型已经自主选全全部数据或分析正确。[包内验收](../result/acceptance/request-fields-20261101/request-package/receipt.json)。
