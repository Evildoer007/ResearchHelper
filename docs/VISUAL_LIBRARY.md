# ResearchHelper图表方案

R186将图形、数据要求与配色沉淀到共享目录。图表库与报告使用同一套离线ECharts实现，App、Skill与demo从主项目构建。

## 一、方案

|类别|图形|
|---|---|
|趋势|折线、多序列、面积、区间带、扇形区间、滚动读数|
|比较|排序条形、棒棒糖、分组柱、哑铃、正负条形、基准点、斜率、双向条形、目标标尺|
|结构|堆叠柱、环形、矩形树、联合构成、旭日、桑基|
|关系|散点、气泡矩阵、证据关系|
|分布|箱线、直方、蜂群、山峦|
|行情与分解|K线、范围、瀑布|
|收益与风险|基期100、回撤、区间收益、超额收益|
|估值|估值带、历史分位|
|矩阵与事件|热力、情景矩阵、事件时间轴|

合计40套。图表库示例分为真实冻结数据和模板。模板不能替换报告缺失数据。面积须为非负规模；占比须可加总；瀑布须闭合；K线须有实际开收低高；置信区间须带方法与水平；收益、分位、密度等接收已计算结果，不由图形层推算。

## 二、配色

研报红蓝、青瓷蓝、椰林绿、墨黑朱砂、纸本灰、夜航蓝、夜林金、紫灰研究、墨青赤金、暖砂棕。每份报告使用一套配色，图例、坐标、网格、纸色同时调整。深色打印还原白底，依据弹层不进入客户打印正文。

## 三、接入范围

App在报告交付和知识入口提供图表方案。当前报告可应用配色及兼容图型，另存HTML保留样式；底稿、原始冻结报告与计算不变。旧历史原版保留原样。

ResearchDesigner通过report-standard、report-detailed两份模板定义选择标准或详细报告，共用modules/visualrenderer/assets/report.html骨架。新研究归档和两种报告导出均使用此模板；依据实际图型与数量组织通栏、双图或三图，兼容的原值对照直接复用已绑定数据，不补造图表。PDF和Word保留图表分组，详细依据跟随各条策略逻辑展开。

自动报告已接入经营同比、利润率哑铃、现金流覆盖分组柱、宏观多线与热力、实际OHLC K线。其余高级方案已实现并可离线预览，但需要任务提供相应数据和已登记计算；未声称所有研究都会自动生成全部40类图形。

Skill通过visuals()按需读取数据要求，export(task_id,visual_theme=...)另存配色版本。默认导出仍为归档原版，视觉切换不触发模型或数据调用，不把全目录塞进研究提示词。

## 四、参考与许可

参考[lieflat-charts](https://github.com/larashero3-dotcom/lieflat-charts)的编辑式表达与方案组织，核对commit为ed436ba56b3cbeee20b9b9966b38a9a9689e239c。其许可证为PolyForm Noncommercial1.0.0，因此未复制或打包上游实现。RH的ECharts构建器及配色独立实现，许可证核对记录保存在docs/references。

## 五、检查

191项模块测试、400组图型与配色构造、40种ECharts实际SVG渲染已通过。两份实际研究冻结内容在1440、1024、390像素下检查原值、公式、焦点、标签、10套配色、样式导出及白底打印。新版仅重呈现既有研究，不新增付费研究。
