# ResearchHelper可视化选型

先确定这幅图要让读者看见什么。工作台登记的图形可用于阅读图例和选择样式。报告自动选图只考虑已取得的数据形状和本条论点的引用；同一幅图可切换的样式由兼容规则决定。图形与配色列表由App或Skill的`visuals()`读取。

## 一、出图顺序

Plotly、Matplotlib和seaborn的官方图例是选型依据。Plotly提供金融图、日期轴、多维编码与交互示例。Matplotlib提供标尺、区间、缺项与打印密度示例。seaborn提供分布、分面、统计区间和连续配色规则。ResearchHelper将这些规则落到一套离线ECharts样式，逐项登记适用数据和参考原页。[Plotly图库](https://plotly.com/python/) [Matplotlib图库](https://matplotlib.org/stable/gallery/index.html) [seaborn图库](https://seaborn.pydata.org/examples/index.html)

1. 确定需要回答的判断。单个读数或仅有两个可比数值时直接写进结论。多个指标必须逐项核对时才用短表；没有可读时间序列时不把两个端点连成趋势。
2. 核对已绑定的观测、对象、计量单位、期间和来源。选时序先核对日期，选比较先核对单位与基期，选构成先核对分母，选区间先核对上下界的含义。
3. 优先放支撑判断的主图。第二张图须回答另一项问题，例如趋势说明何时变化，分布说明期末读数落在样本何处。多条逻辑用到同一窗、同一口径和同一组读数时，共用图表。后文可直接跳转到原图。
4. 标题说清对象和观察，图注放影响读法的期间、单位、基期及方法。点击图题或读数查看原值；打印保留关键口径及来源。

同来源、同指标族、同单位且时间对齐的多条宏观路径已经出现时，后续论点若只比较各路径的起止读数，使用成对端点比较。原路径和每个端点的原值继续可查。引用区间中间值的论点仍可展示完整路径。同一标的收盘价和估值在同一窗口形成一组双轴分图，可与一幅有独立依据的分布或传导图并列。

## 二、按问题选图

### 1. 趋势与行情

|研究问题|可选方案|数据和口径|
|---|---|---|
|变化发生在何时|趋势折线、多序列对照|一条或数条观测路径。保留实际采样日期，缺期断开。|
|多条走势是否同向|同尺度分面|日期和单位一致。面板共用同一纵轴，横向比较转折与幅度。|
|规模怎样积累|规模面积|非负存量或规模，面积从零起。互不加总的净值和收益使用折线。|
|行情的日内区间及收盘位置|价格蜡烛|同一交易日的开收低高四值；只有收盘字段时用走势。|
|对照复合路径或弱化短期噪声|基期指数化、滚动指标|采用已经算出的指数或滚动值，标明统一基日、窗口和频率。|
|收益何时兑现、风险集中于何时|期间收益、超额收益、回撤路径|各期收益为离散读数。注明基准、复权、复利算法和回撤峰值定义。|

行情图按实际日期排列，缺失观测处断开。走势需要至少三个实测读数及一段连续观测，缺项两侧的孤立读数用小方标标出。完整开高低收画蜡烛，收盘序列画折线，并标明复权口径。多资产分面比较幅度时共用纵轴。[Plotly金融图](https://plotly.com/python/financial-charts/) [Plotly日期轴](https://plotly.com/python/time-series/) [Matplotlib缺失值](https://matplotlib.org/stable/gallery/lines_bars_and_markers/masked_demo.html) [seaborn分面](https://seaborn.pydata.org/tutorial/axis_grids.html)

### 2. 对照与估值

|研究问题|可选方案|数据和口径|
|---|---|---|
|哪些样本高或低|横向对照、基准点位|同期间同单位。横条从零起。已有同口径基准，且比较重点是偏离基准时用基准点位。|
|同一对象前后怎样变|分组对照、两期斜率|多个对象具备两期同口径原值。分组适合读数与比幅度，斜率适合读方向与次序。|
|同单位的多组读数差多少|分组对照|同口径同期间，一组一色。营收、利润、现金流是不同类别，用分组对照或矩阵读取。|
|变化方向是否分化|正负变化、分窗口变化|正负图使用有符号变化。分窗口图至少有两个可比指标。|
|两个样本组的数量如何分布|双向对照|两侧使用同尺度，数量为非负且定义清楚。|
|目前距目标和历史位置有多远|目标对照、历史分位、估值区间|目标、区段和样本起止期均可核验。估值带注明历史统计口径；单个估值且缺参考区间时写数值。|

横条保留业务顺序或同口径排名。数值标签在对应条形外端，预留类别与标尺空间。窄栏放不下时优先保留轴、刻度与单位，完整数值可查询原值。配对图保留两期原值，数值差有计算依据时可放在同一视图。[Matplotlib横向条形](https://matplotlib.org/stable/gallery/lines_bars_and_markers/barh.html) [Matplotlib分组柱](https://matplotlib.org/stable/gallery/lines_bars_and_markers/barchart.html) [Matplotlib条形标注](https://matplotlib.org/stable/api/_as_gen/matplotlib.axes.Axes.bar_label.html)

### 3. 构成、归因与流向

|研究问题|可选方案|数据和口径|
|---|---|---|
|整体由哪些部分组成|构成分布、份额环图|同一个总体和互不重叠的分项。排序或精确比差首选直接对照。|
|同时关注父子层级和占比|层级权重、环形层级|父子级加总一致，编码用面积或弧长。层级很深时可切到关键层与明细表。|
|总体怎样从期初到期末|变化桥|期初、期末、各增减项可闭合。剩余差额需明确口径。|
|组规模与组内结构同时比较|联合构成、气泡矩阵|总体和组内分母已知。气泡用面积编码非负数量。|
|观察实际迁移路径|流向分布|流量非负，来源、去向、计量单位和阶段一致；边宽对应实测流量。|

期初值与增减项一致时用变化桥。拆权重用矩形树或环形层级，同时列明各层分母。桑基只用于可计量的流动，产业传导使用有事实依据的关系图。气泡大小用面积表达，联合构成的面积同时含组规模和组内比例。[Plotly瀑布图](https://plotly.com/python/waterfall-charts/) [Plotly矩形树](https://plotly.com/python/treemaps/) [Plotly桑基图](https://plotly.com/python/sankey-diagram/) [Plotly气泡](https://plotly.com/python/bubble-charts/) [Plotly可变宽柱](https://plotly.com/python/bar-charts/#bar-chart-with-variable-width)

### 4. 关系与矩阵

|研究问题|可选方案|数据和口径|
|---|---|---|
|两项读数的对应关系|双指标散点、散点与边沿分布|每个点代表同对象同观察范围的一对数。边沿短刻度对齐主图坐标，展示每个实际读数的位置。|
|哪些时期或样本组不同|数值矩阵|逐格可追溯，缺项留空。跨零读数共用同一零点和发散色阶。|

两变量同图时，先画原始配对。样本足以观察集中位置时，在顶部与右侧加对应坐标的短刻度。横纵轴沿用主图标尺。重复观测在刻度处重合，数量从原值表核对。需要比较计数时采用明确分箱的边际频数。[Plotly边际图](https://plotly.com/python/marginal-plots/) [Matplotlib共享标尺](https://matplotlib.org/stable/gallery/lines_bars_and_markers/scatter_hist.html) [seaborn边沿刻度](https://seaborn.pydata.org/examples/marginal_ticks.html)

数值矩阵借鉴Matplotlib对标注内容与数值色阶的分离。相关矩阵、联合直方图等专门图形需要额外的模型或计算输入。[Matplotlib标注热力](https://matplotlib.org/stable/gallery/images_contours_and_fields/image_annotated_heatmap.html) [seaborn相关矩阵](https://seaborn.pydata.org/examples/many_pairwise_correlations.html) [seaborn联合与边际直方](https://seaborn.pydata.org/examples/joint_histogram.html)

### 5. 分布、区间与情景

|研究问题|可选方案|数据和口径|
|---|---|---|
|样本右尾、左尾和离群点在哪里|频数分布、逐点分布、分位分布|频数直方用等宽分箱。箱宽不同先列频数表，有登记密度计算才画密度。蜂群保留单个观测，箱线明示五数口径。|
|期末或阈值落在样本什么位置|样本区间定位、经验累计分布|区间定位读上下界与期末值；累计分布按实际样本数计算高度，保留重复值与分母。|
|如何比较多条连续分布|多组密度|已计算的同尺度密度网格，明确核、带宽和样本范围。|
|边界有多宽、中心值在哪|观测区间、区间点图、区间带、多层情景带|横向点图适合少数离散区间。连续带需要有序节点；说明观察范围、情景范围或置信区间。|
|假设变化后结果差多少|情景矩阵、情景响应曲线|矩阵适合离散假设。响应曲线要求真实数值设置和已算结果，纵轴共用输出单位。|

经验累计分布按实际样本计数，适合从一个阈值读取累计比例。置信区间描述估计的不确定性，观测区间描述样本离散。分组密度需保留带宽，不从颜色或线宽判断样本量。[Plotly经验累计分布](https://plotly.com/python/ecdf-plots/) [Matplotlib分箱与密度](https://matplotlib.org/stable/gallery/statistics/histogram_normalization.html) [Matplotlib区间端点](https://matplotlib.org/stable/gallery/statistics/errorbar.html) [seaborn分布](https://seaborn.pydata.org/tutorial/distributions.html) [seaborn区间分类](https://seaborn.pydata.org/tutorial/error_bars.html)

### 6. 流程、结构与事件

|研究问题|可选方案|数据和口径|
|---|---|---|
|事实、前提和结论如何连接|证据关系与传导路径|节点来自已采用事实或明确条件。箭头区分证据依赖与待验证的传导。|
|不同公告的先后关系怎样|事件时间轴|核对公开时间、主体和来源。至少两个不同日期有采用的原件。|
|研究对象有什么已核对的上下游关系|结构图|按已披露环节和实际关系组织，统一阅读方向。没有实测流量时用等宽连线。|

流程图用节点承载事实、条件和判断，排序跟随证据中的关系。时间轴刻度依据实际日期。[Matplotlib事件时间线示例](https://matplotlib.org/stable/gallery/lines_bars_and_markers/timeline.html)

## 三、同一组数据的可选读法

|方案|从什么图可切换|阅读与引用|
|---|---|---|
|多序列对照、数值矩阵|日期严格递增、频率一致、同单位多指标。|CPI总项、食品及消费品的多期趋势可切矩阵。各格定位到相应指标和期间的原值。|
|分组对照、数值矩阵|同期间、同单位的多类别观测。|两期财报按营收、利润和现金流分组。类别顺序服务于比较，每个指标独立读数。|
|分组对照、两期斜率|多个对象的两期同单位成对读数。|分组柱读取两期幅度，斜率比较同一指标的变化方向。原值可按指标定位。|
|散点与边沿分布|双指标散点中至少6对完整观测，横纵轴各至少3个不同值。|保留原顺序。点击主图读数核对同一批配对原值，边沿按相同标尺读取各指标分布。|
|经验累计分布|样本区间定位、逐点分布。至少5条有值样本、3个不同读数。|横坐标为原值，纵坐标为小于等于该值的样本数除以总数。重复值合计一次阶跃。实际有期末值时标出期末。|
|区间点图|含中心值的区间带，2至8组。|每行展示上下界与中心值，置信区间沿用原方法和置信水平。只有上下界时沿用原图区间。|
|情景响应曲线|假设轴含至少3档严格递增数值，且有1至4组结果的情景矩阵。|横轴使用实际假设间距。每个标记对应已有计算，缺项断开。只给“保守、基准、乐观”类别时沿用矩阵。|

可切换的方案共用同一版冻结数据。累计分布读取全样本，成对比较读取相应指标的两期值，矩阵读取相应行列的观测。样例页标明实测来源或演示性质。

## 四、可继续扩充的选型

|方案|适合的研究场景|接入前需要具备|
|---|---|---|
|联动散点与边际频数|收益与估值配对规律，兼看各轴离散程度|同时留存配对样本、单变量分箱规则和同一批样本分母。|
|六边形密度或二维分箱|大样本点重叠严重|明确两轴单位、分箱坐标、每个格点计数与边界。|
|相关矩阵带有效样本数|因子和资产的暴露相关|记录共同样本、相关方法、滚动窗口、每格有效样本和缺失处理。|
|敏感性排序|横向比较单因素上下扰动|每项扰动共享基准且保留上下档结果，记录多变量固定方式。|
|排名轨迹|资金或行业名次在连续报告期变化|有稳定成分池、完整排名、并列规则和转入转出说明。|
|分日历收益矩阵|查看交易日异常及星期分布|经核验的交易日历、逐日收益、月与星期索引，休市和缺值分开。|
|事件窗分面|多次事件前后的收益路径|统一事件对齐标尺，单独记录事件日、估计窗口、实际交易日和基准。|
|预测诊断面板|检查模型残差、校准与漂移|冻结同口径预测值、实际标签、样本时间、分箱和独立评估方法。|

这些方案可作为后续取数或计算契约的目标。复杂图形的取舍以其能否回答独立问题、能否在A4宽度保留真实尺度、能否重开依据为准。[Matplotlib图库](https://matplotlib.org/stable/gallery/index.html) [Plotly分面布局](https://plotly.com/python/subplots/) [seaborn图库](https://seaborn.pydata.org/examples/index.html)

## 五、统一风格与交付

- 新研报默认研报红蓝。同一报告保持对象、期间及基准的色彩含义一致。红蓝之外用形状区分读数，正负同时给符号和零轴。连续数值按明度，跨零差异用对称发散色阶。[seaborn配色原则](https://seaborn.pydata.org/tutorial/color_palettes.html)
- 保留坐标轴、刻度和单位。时间轴在窄窗与标准版分别减少至约4和6个刻度。纯折线关闭逐点标记，末值与少量有据的极值标注避开曲线。常规布局用留白和实线。零线、临界值及必要的比较基准按含义区分。数据矩阵的格子对应实际记录。对客报告版式由已有报告模板负责，左侧目录独立于A4正文。
- App和Skill按各条策略逻辑引用的冻结证据选图。连续观测用走势，同日可比读数用横向比较，同口径多序列可共用时间轴。一两个读数直接写进正文，可点开原值、单位与来源。同口径多项金额需要逐项核对时使用紧凑表格。
- App从报告的图表方案进入适用选项，配色可以另存，预览图可导出为PNG。Skill通过visuals()查看要求，通过export的visual_profile参数生成同版呈现。HTML保留已选样式，打印和Word图形沿用同一冻结数据。
- 模板样例与真实样例有明确标识。报告缺项时保留足以支撑判断的现有读数和限制。每次改动核对桌面、窄窗、移动宽度与A4打印，检查原值链接和静态导出。

方案和官方参考页由visual_catalog.py登记，浏览器目录由它生成。visual-library.js实现离线渲染，report_designer.py依据冻结数据检查选型，publication_graphics.py处理静态输出。
