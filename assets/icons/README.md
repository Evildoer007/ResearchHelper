# ResearchHelper图标

来源为用户提供的researchhelper-icons.zip，归档SHA-256见icon-manifest.json。SVG、ICNS和ICO保留原始字节；PNG直接提取自对应ICNS的1024像素PNG块。

- researchhelper-mark.svg：红色研究标志。
- researchhelper-logo.svg：完整字标。
- researchhelper-app-icon-tile-light.*：浅色App图标。
- researchhelper-app-icon-tile-dark.*：深色App图标。

网页运行副本为brand.svg、app-icon.svg、app-icon-dark.svg和login/wordmark.svg。启动及登录使用相同字标，深色背景只适配文字墨色。App安装图标、Dock图标和Skill标志均来自本目录；常规打包仅校验及复制，不重新绘制。
