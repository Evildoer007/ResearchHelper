# ResearchHelper品牌资源

与OptionHelper使用同一目录层级：`assets/icons`。

- `researchhelper-mark.svg`：红色四节点研究标记。
- `researchhelper-logo.svg`：ResearchHelper字标。
- `researchhelper-app-icon-tile-light.svg`：白色圆角方形App图标源文件。
- 同名PNG、ICNS、ICO：现用macOS与Windows安装图标。
- `icon-manifest.json`：受控文件哈希，打包时校验。

前端的brand.svg、app-icon.svg和login/wordmark.svg是离线运行副本，须与本目录源文件完全一致。右下角任务助手使用OH同源Bloub组件，不再使用品牌标记充当助手。
